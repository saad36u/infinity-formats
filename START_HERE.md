## 🆘 Need Help?

### Common Questions

**Q: How do I change the WhatsApp number?**
A: Open `src/App.tsx`, find `970599999999`, replace with your number. See `CUSTOMIZATION_GUIDE.md` for details.

**Q: How do I deploy?**
A: Easiest way: Read `QUICK_START.md` → Step 4. Or see `DEPLOYMENT.md` for all options.

**Q: Can I change the colors?**
A: Yes! See "Change Color Scheme" section in `CUSTOMIZATION_GUIDE.md`.

**Q: Where do I upload files?**
A: Upload everything in the `dist` folder to your hosting. See `DEPLOYMENT.md`.

**Q: What if the logo doesn't show?**
A: Make sure your logo is saved as `public/logo.png`, then rebuild with `npm run build`.

### Still Stuck?

1. Check the error message
2. Search in the relevant guide
3. Try rebuilding: `npm install && npm run build`
4. Clear browser cache: Ctrl+Shift+R

## 📱 Contact Information Format

**Correct WhatsApp format in code:**
```
https://wa.me/970XXXXXXXXX?text=Hello
```
- No spaces
- No + symbol in URL
- Country code + number

**Example:**
- ✅ Correct: `970599123456`
- ❌ Wrong: `+970 59 912 3456`
- ❌ Wrong: `059 912 3456`
